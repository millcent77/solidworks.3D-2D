此项目我是为了用于，使用solidworks 3D档案sldprt或者x_t档直接转档到2D-dwg档案并自动标注尺寸，现有问题是：1，必须安装有solidworks才能运行；2、标注的尺寸，总是混乱，重要尺寸没有标注出来，或者标注的尺寸重叠严重
The purpose of this project is to automatically convert SolidWorks 3D files, such as SLDPRT or X_T files, directly into 2D DWG drawings with automatic dimensioning.

The current issues are:

1. **SolidWorks dependency**
   SolidWorks must be installed on the computer for the program to run.

2. **Poor automatic dimensioning**
   The automatically generated dimensions are often disorganized. Important dimensions may be missing, while unnecessary dimensions are added. In addition, dimension lines and text frequently overlap, making the drawing difficult to read and unsuitable for direct use in production.

The goal is to develop a more independent and reliable solution that can generate practical 2D DWG drawings from 3D models and automatically identify and annotate the important manufacturing dimensions.
